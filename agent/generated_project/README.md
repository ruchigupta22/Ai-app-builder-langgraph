## Usage

- **Button Clicks**: Click the on‑screen buttons to perform actions such as submitting data, toggling views, or resetting the form.
- **Keyboard Shortcuts**:
  - `Ctrl + S` – Save or submit the current form.
  - `Ctrl + R` – Reset the application state.
  - `Esc` – Close any open modal or clear input fields.
- **Error Handling**:
  - The app validates inputs in real time and displays clear error messages beneath the affected fields.
  - If an unexpected error occurs, a toast notification appears with a brief description and a suggestion to retry.
