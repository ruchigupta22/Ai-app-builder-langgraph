## Overview

AI App Builder is a multi-agent software engineering system built using LangGraph, LangChain, Groq LLMs, and Pydantic.

The project explores how multiple AI agents can collaborate to transform a simple user request into a structured software project.

The workflow consists of planning, architecture design, task generation, and code generation using a stateful LangGraph workflow.

---

## Architecture

```text
User Prompt
     ↓
Planner Agent
     ↓
Project Plan
     ↓
Architect Agent
     ↓
Task Plan
     ↓
Coder Agent
     ↓
Generated Project Files
```

---

## Planner Agent

The Planner Agent receives the user's request and converts it into a structured engineering plan.

The generated plan includes:

- Application name
- Description
- Tech stack
- Features
- Required files

The output is validated using Pydantic models.

---

## Architect Agent

The Architect Agent receives the planner output and generates implementation tasks.

Responsibilities:

- Analyze the project plan
- Break the project into implementation steps
- Generate file-level tasks
- Prepare instructions for the coding agent

---

## Coder Agent

The Coder Agent executes implementation tasks generated by the Architect Agent.

Responsibilities:

- Read existing files
- Generate code
- Write files to disk
- Track implementation progress using state

The coder agent uses LangGraph state management to process tasks sequentially.

---

## State Management

The project uses structured Pydantic models for agent communication.

### Plan

Stores:

- Name
- Description
- Tech stack
- Features
- Files

### TaskPlan

Stores:

- Implementation tasks
- File-level development instructions

### CoderState

Stores:

- Current task plan
- Current implementation step
- Current file content

This enables the coding agent to maintain progress across multiple implementation steps.

---

## Tools

The project includes custom filesystem tools:

### write_file()

Writes generated content to disk.

### read_file()

Reads file contents from the generated project.

### list_files()

Lists project files.

### get_current_directory()

Returns the current project directory.

These tools allow the coding agent to interact with the filesystem.
